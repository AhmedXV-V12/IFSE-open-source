أول إصدار مفتوح المصدر: محرك بحث ومفهرس تشغّلهم بنفسك

أكتوبر 2026
  • مفتوح المصدر تحت رخصة AGPL-3.0 — الكود كله متاح، وأي حد يشغّل نسخة معدّلة كخدمة على الإنترنت لازم ينشر كودها.
  • المفهرس جزء من المشروع — خدمتين منفصلتين في Docker: المفهرس (زاحف + فهرسة + لوحة تحكم) وخدمة البحث. أمر واحد يشغّلهم: docker compose up.
  • فلترة الفهرسة بإيدك — قواعد حظر أو سماح حسب الموقع، أو جزء من الرابط، أو تعبير منتظم، أو بداية المسار، أو كلمة في الصفحة، أو كلمة في العنوان، أو اللغة. وكمان حد أدنى لعدد الكلمات، وحد أقصى لحجم الصفحة، ووضع «القائمة البيضاء فقط».
  • تجربة الفلاتر قبل تطبيقها — جرّب أي رابط وشوف هيتقبل ولا لأ وليه، وشوف معاينة بالصفحات اللي هتتشال من الفهرس الحالي قبل ما تشيلها.
  • متصفح الفهرس — كل الصفحات المفهرسة قدامك: تبحث فيها، وتفلترها بالموقع واللغة، وترتبها، وتشوف تفاصيل كل صفحة وتاريخها، وتمسحها أو تعيد زحفها، أو تحظر موقع كامل بضغطة.
  • سجل الفهرسة — كل صفحة اتضافت أو اتحدثت أو اترفضت أو اتشالت، وكل تغيير في الفلاتر والإعدادات، متسجّل بوقته وسببه.
  • Customize my engine — زر الترس في ركن الصفحة الرئيسية بيفتح محرر تصميم: حرّك مربع البحث لفوق أو تحت أو يمين أو شمال أو اسحبه بحرية، وغيّر الألوان والخلفية (لون، أو تدرّج، أو صورة)، وضيف اختصارات لمواقعك وصور على الصفحة، وأظهر أو أخفِ أي جزء. التصميم بيتحفظ على جهازك، وتقدر تصدّره وتستورده كملف.
  • بدون حَكَم ذكي وبدون قوائم حظر جاهزة — النسخة المفتوحة بتبدأ بفهرس فاضي وفلاتر فاضية؛ صاحب المحرك هو اللي يقرر إيه اللي يدخل.
  • بحث بنفس هوية IFelx — نفس الواجهة الغامقة والشعار والخطوط، ونفس توحيد الحروف العربية (أ/إ/ا، ة/ه، ى/ي، والتشكيل) في الفهرسة والبحث.
  • زحف مهذّب وآمن — يحترم robots.txt ووسم noindex/nofollow دايماً، ويستنّى بين صفحات نفس الموقع، وما يطلبش أي عنوان في شبكتك الداخلية.
